# Reports Directory
Holds static synthesis logs, power estimations, timing reviews (STA), and logic cell count breakdowns.

## Standard Reports Expected:
1. `area_report.txt`: Total NAND2 cell equivalents and LUT usage.
2. `power_report.txt`: Dynamic switching power relative to static subthreshold leakage.
3. `timing_sta_report.txt`: Setup/Hold Slack margins under maximum design frequencies.
